# Portfolio — Amina Maddouri

Portfolio académique et professionnel statique, prêt pour GitHub Pages.

## Publication sur GitHub Pages
1. Créer un repository public, par exemple `amina-maddouri.github.io`.
2. Ajouter tous les fichiers de ce dossier à la racine du repository.
3. Dans GitHub : Settings → Pages.
4. Source : **Deploy from a branch**.
5. Branch : **main** et dossier **/(root)**.
6. Enregistrer. GitHub affichera ensuite l’URL publique.

Si le repository s’appelle exactement `amina-maddouri.github.io`, l’adresse sera généralement :
`https://amina-maddouri.github.io/`

## Fichiers
- `index.html` : site
- `style.css` : design responsive
- les deux PDF : CV téléchargeables depuis le site
